## 📌 Project Overview
This repository contains an end-to-end Machine Learning pipeline designed to predict spot freight rates. Using historical load data, the pipeline performs data auditing, handles anomalies (e.g., negative weights and missing values), engineers spatial/temporal features, and trains a **LightGBM Regressor** using a **5-Fold Cross-Validation** strategy.

## 🛠️ Data Quality Handling & Feature Engineering
1. **Negative Weight Correction:** Identified physically impossible negative values in `weight` (down to `-47,500.0` lbs) and applied absolute value transformations (`.abs()`).
2. **Missing Data Imputation:** Imputed missing values in `weight` (300 missing) and `market_index` (374 missing) using fold-level medians to strictly avoid data leakage.
3. **Feature Engineering:**
   * **Temporal:** Derived `day_of_week`, `day_of_month`, and `is_weekend` from `date`.
   * **Logistics Interaction:** Engineered `weight_per_mile` (`weight / distance`) to capture vehicle capacity utilization.
   * **Categoricals:** Encoded `pickup`, `delivery`, and `equipment` as native categorical types for LightGBM split optimization.
